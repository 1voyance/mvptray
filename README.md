# Mihomo Tray (Rust + Tauri)

Трей для VPN-клиента [Mihomo](https://github.com/MetaCubeX/mihomo) под Windows.

## Запуск

1. Двойной клик по `mihomo-tray.exe`. Откроется главное окно, иконка появится в трее.
2. Чтобы трей стартовал вместе с Windows **с правами администратора** (тогда включение и выключение VPN проходят без окна UAC), запустите `install-autostart.bat`. Скрипт:
   - создаст задачу планировщика `MihomoTrayRs`;
3. Вернуть всё как было: `uninstall-autostart.bat`.

Отдельные DLL рядом с exe не нужны. WebView2 Runtime в Windows 11 уже есть.

## Что умеет

- **Иконка в трее.** Зелёная: всё работает. Жёлтая: служба запущена, но нода не отвечает или Mihomo не отвечает. Серая: VPN выключен. В подсказке показаны нода, пинг и скорость.
- **Клик по иконке** открывает мини-окно: кнопка питания, скорость, режим, быстрое добавление сайта в VPN.
- **Двойной клик** открывает главное окно. Правый клик открывает меню.
- **Обзор:** статус, цепочка `Proxy → Auto → нода`, пинг, график скорости, режимы «По правилам», «Всё через VPN» и «Напрямую».
- **Ноды:** выбор сервера в каждой группе и проверка пинга.
- **Мои правила:**
  - для правила можно выбрать действие: через VPN (в нужную группу), напрямую или блокировать;
  - правила можно редактировать, менять их порядок кнопками ↑↓, выделять несколько сразу, удалять их пачкой и менять им действие;
  - есть импорт из файла или вставленного списка и экспорт в .txt.
- **Сайты:** список последних адресов, раздел «Не открываются» и кнопки «В VPN», «Напрямую» и «Блок» прямо в строке.
- **Уведомления:** VPN упал или поднялся, сменилась нода, нода не отвечает, обновилась подписка. Есть автоперезапуск службы, по умолчанию он выключен.

## Новое в 2.1

- **Умный выбор ноды.** Оценивает пинг, его разброс, потери и скорость. Мёртвую ноду меняет примерно за 30 секунд. Любую ноду можно закрепить.
- **Discord.** Трей хранит копию файлов discord-voice-proxy. Когда Discord обновится, файлы сами появятся в новой папке `app-…`.
- **Подсказка «сайт не открывается».** Маленькое окно в углу с кнопкой «В VPN». Фокус оно не забирает.
- **Игровой режим.** Пока запущена игра или OBS:
  - тест скорости на паузе;
  - нода меняется, только если умерла;
  - подсказки не всплывают.
- **Обновления в Настройках:**
  - ядро Mihomo — с автоматическим откатом, если новая версия не запустится;
  - базы GeoIP, наборы правил и панель Zashboard;
  - сам трей: если рядом лежит `mihomo-tray.new.exe`, достаточно нажать «Установить».

## Новое в 2.3

- **Трей не нагружает систему в фоне.** Скрытые окна ставят анимации на паузу, а через 2 минуты простоя выгружаются целиком: процессы WebView2 завершаются, память освобождается. По клику окно создаётся заново (первое открытие после простоя — на долю секунды дольше). Время простоя меняется переменной `MIHOMO_TRAY_IDLE_SECS`.
- **Нет шквала запросов пинга** после перезагрузки конфига: после неудачи пауза 30 секунд, ноды подписки проверяются через провайдера.
- **Массовая смена действия у правил** — одной записью конфига и одной перезагрузкой Mihomo.
- **Discord и TUN.** Если в Mihomo включён режим TUN, файлы discord-voice-proxy не нужны: раздел в настройках показывает это и ничего не копирует в папку Discord.

## Новое в 2.4

- **Обновления с GitHub.** Трей сам проверяет новые версии в [Releases](https://github.com/1voyance/mvptray/releases) — при запуске и раз в сутки — и присылает уведомление. В «Настройках → Обновления» видно, что нового, а кнопка «Обновить трей» скачивает новую версию, перезапускает трей и сохраняет прошлую как `mihomo-tray.prev.exe`. VPN при этом не выключается. Отключается тем же переключателем, что и проверка Mihomo.

## Установка с нуля

1. Поставьте [Mihomo](https://github.com/MetaCubeX/mihomo/releases) в `C:\mihomo` (или в другую папку и задайте переменную `MIHOMO_DIR`), с вашим `config.yaml` и службой Windows.
2. Скачайте `mihomo-tray-vX.Y.Z.zip` из [Releases](https://github.com/1voyance/mvptray/releases) и распакуйте так, чтобы получилось `C:\mihomo\tray-rs\mihomo-tray.exe`.
3. Запустите `mihomo-tray.exe`, подписку добавьте в разделе «Подписки». Для автозапуска — `install-autostart.bat`.

В репозитории нет ничьих настроек, подписок и логов: `settings.json`, `logs\` и `backups\` трей создаёт сам при первом запуске.

## Выпуск новой версии (для разработчика)

Поднимите `version` в `source/src-tauri/Cargo.toml` и `tauri.conf.json`, закоммитьте и отправьте тег: `git tag v2.4.1 && git push origin v2.4.1`. GitHub Actions соберёт `mihomo-tray.exe` и опубликует релиз — у всех установленных треев появится уведомление.

## Надёжность

- **Резервная копия.** Перед каждым изменением `config.yaml` в `tray-rs\backups` сохраняется копия. Хранятся последние 15, восстановить можно в «Настройках».
- **Безопасная запись.** Файл записывается атомарно. Если Mihomo отклонил новый конфиг, файл автоматически возвращается к прежнему виду, и при добавлении, и при удалении правил.
- **Проверка ввода.** Ссылки, `*.домен`, порты и пути очищаются сами. Запятые, пробелы и прочий мусор отклоняются.
- **Формат файла сохраняется:** комментарии, пустые строки, CRLF и BOM остаются как были.
- **Адрес API** и `secret` читаются из `config.yaml`, а не зашиты в программу.
- **Логи** пишутся в `tray-rs\logs\tray.log` (до 1 МБ, с ротацией).
- **Повторный запуск** открывает окно уже работающего трея, а не убивает процесс.

## Сборка из исходников

Исходники лежат в `source\`. Нужны Rust и компилятор C++: либо Visual Studio Build Tools, либо MinGW (`winget install BrechtSanders.WinLibs.POSIX.UCRT` и набор `stable-x86_64-pc-windows-gnu` в rustup — так собрана текущая версия; при такой сборке рядом с exe должен лежать `WebView2Loader.dll`). После этого запустите `build.bat`. Тесты: `cargo test --release` в `source\src-tauri`.
