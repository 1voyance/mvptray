## Зачем нужен Mihomo Tray

**Mihomo Tray** превращает консольное ядро Mihomo (запущенное как служба Windows) в удобный десктопный VPN-клиент в духе **Linear / Raycast**:

- **Один клик в трее** — компактный `flyout` с кнопкой питания, скоростью в реальном времени, переключением режима и быстрым добавлением сайта в VPN.
- **Умный выбор сервера** — постоянная оценка пинга, джиттера, потерь и реальной скорости; при падении ноды переключение занимает ~30 секунд.
- **Автообход блокировок подписок (Cloudflare WARP)** — если подписка обрывается из-за ТСПУ (16 КБ на Cloudflare) или недоступна напрямую, клиент сам генерирует персональный локальный X25519-ключ WARP, поднимает скрытый `WARP-Sub` поверх рабочей UDP-ноды и скачивает весь список серверов.
- **Ноль нагрузки в фоне** — скрытые окна ставят анимации на паузу и через 2 минуты простоя полностью выгружают процессы WebView2 из памяти.

## Возможности

| Раздел | Что умеет |
| :--- | :--- |
| **Трей и Flyout** | Индикатор статуса (зелёный / жёлтый / серый), тултип с нодой, пингом и скоростью. Клик — компактное окно, двойной клик — главное окно. |
| **Обзор** | Статус подключения, цепочка `Proxy → Auto → нода`, график скорости в реальном времени, режимы «По правилам», «Всё через VPN» и «Напрямую». |
| **Ноды и умный выбор** | Все группы и серверы, проверка пинга, закрепление любимой ноды, автотест скорости (раз в 6 часов в простое, не мешает трафику). |
| **Подписки** | Добавление, смена ссылки, переключение «все сразу / только активная», автоматический **WARP-обход** (включая частичный bootstrap при 0 нод) и бейдж `WARP`. |
| **Мои правила** | Домены, программы (`PROCESS-NAME`) и IP-сети → в VPN, напрямую или блок. Редактирование, порядок `↑↓`, массовые действия, импорт и экспорт `.txt`. |
| **Сайты и подсказки** | Живой список адресов, вкладка «Не открываются» и ненавязчивое всплывающее окно с кнопкой «В VPN» (фокус не забирает). |
| **Игровой режим** | Автоматически определяется запуск игр и OBS: тесты скорости ставятся на паузу, нода не переключается без падения, подсказки не мешают. |
| **Discord** | Автоматическое поддержание `discord-voice-proxy` после обновлений Discord (при включённом TUN не вмешивается). |
| **Обновления** | В один клик обновляет ядро Mihomo (с автооткатом при сбое), базы GeoIP/правила/Zashboard и сам трей с GitHub Releases. |

## Что нового в v2.5.0

- **Полный редизайн UI** — строгий графитовый минимализм (`#0a0a0c`, 1px бордеры, изумрудный акцент), безрамочное главное окно со своей шапкой, новая графитовая иконка приложения.
- **Переработанная навигация и Настройки** — «Настройки» вынесены в нижнюю часть сайдбара и разбиты на 4 чистые вкладки (*Основные*, *Уведомления и подсказки*, *Discord*, *Обновления и система*).
- **Встроенный WARP-обход подписок** — при `EOF`, таймауте или `503` трей сам регистрирует персональный Cloudflare WARP-ключ, создаёт скрытую группу `WARP-Dialer` для подбора UDP-ноды (не трогая вашу активную ноду `Auto`) и обновляет подписку.
- **Автоисправление сломанного DNS** — при старте тихо заменяет нерабочий `https://77.88.8.8/dns-query` на стабильные DoH-серверы (`dns.adguard-dns.com` / `dns.google`), не затрагивая кастомные настройки.

## Установка

### Требования
- **Windows 10 / 11 (x64)** — WebView2 Runtime уже встроен в систему.
- Установленное ядро **[Mihomo](https://github.com/MetaCubeX/mihomo/releases)** в `C:\mihomo` *(или в другой папке с переменной окружения `MIHOMO_DIR`)* с вашим `config.yaml` и службой Windows.

### Быстрый старт

1. Скачайте установщик `mihomo-tray-setup-vX.Y.Z.exe` **или** портативный архив `mihomo-tray-vX.Y.Z.zip` со страницы **[Releases](https://github.com/1voyance/mvptray/releases/latest)**.
2. Если используете архив — распакуйте в `C:\mihomo\tray-rs\mihomo-tray.exe` и запустите.
3. Для автозапуска вместе с Windows **с правами администратора** (включение/выключение службы без окна UAC) запустите `install-autostart.bat` *(создаст задачу `MihomoTrayRs` в Планировщике; удаление — `uninstall-autostart.bat`)*.
4. Откройте раздел **«Подписки»** и вставьте ссылку от вашего VPN-провайдера.

> [!NOTE]
> **Про Windows SmartScreen:** бинарник не подписан платным коммерческим сертификатом, поэтому при первом запуске Windows может показать предупреждение *«Система Windows защитила ваш компьютер»*. Нажмите **«Подробнее» → «Выполнить в любом случае»** (или перед распаковкой `.zip` откройте *Свойства → «Разблокировать»*).

## Надёжность и безопасность

- **Атомарная запись и автооткат** — перед любым изменением `config.yaml` создаётся резервная копия в `tray-rs\backups\` (хранятся последние 15, восстанавливаются в один клик). Если Mihomo отклонит новый конфиг, файл откатывается автоматически.
- **Сохранение форматирования** — комментарии, пустые строки, `CRLF/LF` и `BOM` в вашем `config.yaml` не ломаются.
- **Персональные ключи** — если включается WARP-обход, ключ X25519 генерируется локально на вашем ПК и хранится только в вашем `config.yaml`. Никакие сторонние зеркала не используются.
- **Чистый репозиторий** — `settings.json`, `logs\tray.log` (ротация по 1 МБ) и `backups\` создаются локально при первом запуске.
- **Одиночный экземпляр** — повторный запуск `mihomo-tray.exe` просто открывает уже работающее окно.

## Частые вопросы

<details>
<summary><b>Мешает ли WARP-обход обычному трафику, пингу или скорости?</b></summary>

Нет. Скрытая нода `WARP-Sub` (`hidden: true`) не подключена ни к `Proxy`, ни к `Auto` и используется **только** в момент скачивания файла подписки (раз в сутки или по кнопке «Обновить»). Весь остальной трафик идёт напрямую через ваши VPN-ноды или `DIRECT`.

</details>

<details>
<summary><b>Где хранятся настройки, логи и бэкапы?</b></summary>

В папке `tray-rs\` рядом с `config.yaml` (по умолчанию `C:\mihomo\tray-rs\`). Открыть папку с логами и конфигом можно прямо из раздела *Настройки → Обновления и система*.

</details>

<details>
<summary><b>Как изменить время выгрузки окна из памяти?</b></summary>

Задайте переменную окружения `MIHOMO_TRAY_IDLE_SECS` (по умолчанию `120` секунд).

</details>

## Сборка из исходников

Исходный код находится в папке [`source/`](source/). Для сборки нужны **Rust** и тулчейн C++ (**MSVC Build Tools** или **MinGW / llvm-mingw**):

```powershell
cd source/src-tauri

# Прогнать тесты
cargo test --release

# Собрать релизный бинарник
cargo build --release
```

Готовый файл появится в `source/src-tauri/target/release/mihomo-tray.exe`. Также можно использовать [`build.bat`](build.bat).
